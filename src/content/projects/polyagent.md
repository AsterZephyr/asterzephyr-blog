An AI agent platform built with Go, Rust, and Python. Features isolated WASI sandboxes for code execution, token budget controls to prevent runaway costs, multi-agent workflow coordination, and provider-agnostic LLM integration. Includes step-by-step workflow replay for debugging and Prometheus metrics with distributed tracing for observability.
