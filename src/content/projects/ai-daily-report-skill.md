A Claude Code skill that scrapes Hacker News and HuggingFace Papers daily, deduplicates, scores, and categorizes entries, then generates a structured Chinese-language intelligence report. Uses parallel sub-agents for concurrent data fetching. Output is saved as local Markdown with optional publishing to Feishu Wiki.
