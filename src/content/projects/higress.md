An AI-native API gateway built on Envoy, providing intelligent traffic routing, rate limiting, and a Wasm-based plugin ecosystem. Features LLM request routing with model failover, token-level rate limiting, prompt caching, and seamless integration with major AI providers. Ideal for serving AI workloads at scale with observability and security built in.
